# 央廣1號 Rti 行動廣播車 · 3D 互動導覽

中央廣播電臺 Radio Taiwan International｜雙語 3D 互動導覽（Three.js）

## 線上瀏覽

https://rti-git.github.io/rti-van-tour/

## 功能

- Minecraft 風格的 3D 行動廣播車模型，可旋轉、縮放、透視車內
- 12 項車載設備互動圖鑑（車外全覽 / 車內透視 / 電視外翻 / 衛星發射）
- 5 個任務情境地圖場景（央廣基地、前進校園、多語聯合聽友、災區韌性、雙十國慶）
- 中英雙語切換
- 支援桌機與手機（RWD）

## 技術

單一 HTML 檔，Three.js r128 + Tailwind CSS，無需後端。
